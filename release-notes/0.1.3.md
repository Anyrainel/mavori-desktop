# Mavori 0.1.3

- Updated Connections settings and account management. Open Settings → Connections to review your connected accounts.

**Update:** use **Help → Check for updates** in Mavori, then restart when prompted. If the update fails, install the current version from [Download Mavori](https://mavori.ai/download).

**Install:** Windows x64, Apple Silicon and Intel Mac, and Linux x64. Choose the matching asset below. On Windows, open the EXE; on Mac, open the DMG and drag Mavori into Applications; on Linux, allow the AppImage to run as a program and open it.

Windows may show an unknown-publisher warning because the direct installer is unsigned. If installation is blocked, use the [web app](https://app.mavori.ai/) and contact support.
