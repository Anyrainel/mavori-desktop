# Mavori 0.1.5

- Improved Interactive Brokers desktop connection setup and broker credential guidance. Open Settings → Connections to get started.
- Portfolio charts now include broker valuation history where available, with approximate values clearly identified.

**Update:** use **Help → Check for updates** in Mavori, then restart when prompted. If the update fails, install the current version from [Download Mavori](https://mavori.ai/download).

**Install:** Windows x64, Apple Silicon Mac, and Linux x64. Choose the matching asset below. On Windows, open the EXE; on Mac, open the DMG and drag Mavori into Applications; on Linux, allow the AppImage to run as a program and open it.

Windows may show an unknown-publisher warning because the direct installer is unsigned. If installation is blocked, use the [web app](https://app.mavori.ai/) and contact support.
